# OKO — frontend

Vue 3 + PrimeVue 4 + Tailwind 4. Повна документація (локальний запуск, Supabase, деплой, CI) — у [кореневому README](../README.md).

```bash
pnpm install
pnpm dev          # http://localhost:5173 (потрібен frontend/.env.local, див. .env.example)
pnpm run check    # те саме, що CI: oxlint, eslint, prettier, vue-tsc, build
```
