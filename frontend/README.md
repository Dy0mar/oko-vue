# OKO: frontend

Vue 3 + PrimeVue 4 + Tailwind 4. Full docs (local setup, Supabase, deployment, CI) are in the [root README](../README.md).

```bash
pnpm install
pnpm dev          # http://localhost:5173 (needs frontend/.env.local, see .env.example)
pnpm run check    # same as CI: oxlint, eslint, prettier, vue-tsc, build
```
